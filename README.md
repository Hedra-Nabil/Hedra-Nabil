<h2>🏗️ How I Think About Software</h2>
 
```text
Readable → Maintainable → Testable → Observable → Automated → Scalable
```
 
> **Don't introduce complexity because it looks impressive. Introduce complexity only when the problem actually requires it.**

**APIs:** every integration needs authentication, retries, idempotency, logging, monitoring, rate limiting, validation and graceful failure.
**Infra:** VPS · Ubuntu · Docker Compose · Nginx · SSL/DNS · Cloudflare WAF · GitHub Actions · performance troubleshooting.
**AI:** used where it creates real operational value — assistants, LLM integrations, n8n workflows, speech processing, accessibility.
